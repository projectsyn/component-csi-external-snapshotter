= Parameters

The parent key for all of the following parameters is `csi_external_snapshotter`.

== `namespace`

[horizontal]
type:: string
default:: `syn-csi-external-snapshotter`

The namespace in which to deploy this component.

== `manifestVersion`

[horizontal]
type:: string
default:: `${csi_external_snapshotter:images:external-snapshotter:tag}`

The version (tag) to use when rendering the Kustomization for the CSI external snapshotter.

== `images`

[horizontal]
type:: dict
default:: See https://github.com/projectsyn/component-csi-external-snapshotter/blob/master/class/defaults.yml[`class/defaults.yml`]

The container images used by the component.


== `kustomizeInput`

[horizontal]
type:: dict
default:: `{}`

Additional Kustomize input for the CSI external snapshotter Kustomization.
